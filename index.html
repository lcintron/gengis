GenGIS (G2)

Version

A standalone map building tool. Works offline as an installed Progressive Web App (map tiles you have viewed are cached) or inside Electron.

Shortcuts

V select · G move · K scale (drag a handle: Shift keeps proportions, Alt from the center) · F presenter · M marker · T text · L line · P polygon · R shapes · C circle · S image · I icon · N annotate · D distance · A area · Esc cancel · Del delete · Ctrl+Z/Y undo/redo · Ctrl+D duplicate · Ctrl+S save file · / search

Open with URL parameters: ?q=Eiffel+Tower, ?lat=48.858&lon=2.294&zoom=16, ?center=48.858,2.294, ?poi=cafe.

Add an icon

Icons by Lucide (ISC licence). The icon you pick goes into the image library; click the map to place it.

Data sources

Free, no API keys.

  • Map tiles: OpenStreetMap, OSM Humanitarian, OpenTopoMap, CyclOSM, CARTO, Esri World Imagery. Each has its own usage policy and attribution shown on the map.
  • Address and place search: Nominatim (OpenStreetMap). Fair use: no bulk or automated queries.
  • Points of interest: Overpass API.
